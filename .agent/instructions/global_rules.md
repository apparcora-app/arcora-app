\# Arcora / LifeOS Codex Instructions



\## Project

Arcora is a premium life admin dashboard built with React, TypeScript, Tailwind CSS, Firebase Auth, Firestore, Firebase Storage, React Router, Recharts, and Framer Motion.



\## Main Rules

\- Preserve existing UI, routes, layouts, styling, animations, and working features.

\- Do not remove working code unless clearly replacing it with safer code.

\- Do not change Arcora branding.

\- Do not create duplicate systems if an existing system already works.

\- Give full rewritten files only when changing files.

\- Never send undefined fields to Firestore.

\- Guard Firebase mock mode and incomplete Firebase config.

\- Always check auth, Firestore subscriptions, cleanup/unsubscribe logic, loading states, and routing before editing.

\- Run build/typecheck/lint when available.

\- After changes, explain files changed and give manual testing steps.



\## Preferred Workflow

1\. Analyze first.

2\. Report issues.

3\. Ask before large rewrites.

4\. Fix only confirmed problems.

5\. Validate with available commands.
